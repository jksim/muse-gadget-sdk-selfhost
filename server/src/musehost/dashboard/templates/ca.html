Trust this host

musehost uses its own certificate authority (CA), created on this Pi. Your browser warns about the dashboard until you trust it, once per computer.

Its SHA-256 fingerprint: {{ fingerprint }}
Check it matches what musehost dashboard-password printed on the Pi.

Download the CA certificate

Windows

Open the downloaded file, choose Install Certificate, then Current User, Place all certificates in the following store, Trusted Root Certification Authorities. Restart the browser.

macOS

Open the file in Keychain Access (login keychain), double-click the certificate, and under Trust set Always Trust.

Linux

Firefox and Chrome: Settings, Certificates, Authorities, Import, and trust it for websites. System-wide: copy it to /usr/local/share/ca-certificates/musehost.crt and run sudo update-ca-certificates.

Then open https://{{ host }}/dashboard.
